# MinGPT 复现 - 字符级语言模型

本项目是基于 PyTorch 实现的迷你 GPT 模型复现，核心目的是学习和理解解码器-only Transformer（GPT 架构）的核心原理，非原创研究，仅用于学习实践。

模型基于字符级语言建模任务，使用 tiny Shakespeare（迷你莎士比亚）数据集进行训练，完整复现了 GPT 的核心模块与训练流程。

## 模型架构
- 解码器-only Transformer（GPT 风格）
- 带因果掩码的多头自注意力机制（防止模型“偷看”未来token）
- 残差连接 + 层归一化（pre-norm 结构，先归一化再进入注意力/前馈层）
- 位置嵌入 + token 嵌入（捕捉序列位置信息与字符语义信息）
- 前馈网络（扩张系数为4，提升模型表达能力）
- Dropout 正则化（防止过拟合）
- 自定义权重初始化（高斯正态分布 N(0, 0.02)，保证训练稳定性）

## 超参数配置
| 超参数         | 数值  | 说明                     |
|----------------|-------|--------------------------|
| batch_size     | 64    | 并行处理的样本批次大小   |
| block_size     | 256   | 模型最大上下文窗口长度   |
| n_embd         | 384   | 词嵌入/隐藏层维度        |
| n_head         | 6     | 多头注意力的头数         |
| n_layer        | 6     | Transformer 解码器层数   |
| learning_rate  | 3e-4  | 优化器学习率（AdamW）    |
| max_iters      | 5000  | 总训练迭代次数           |
| dropout        | 0.2   | 随机失活率（正则化）     |

## 训练说明
模型采用自监督学习方式，在莎士比亚文本语料上训练：
- 任务：根据前序字符预测下一个字符
- 损失函数：交叉熵损失（F.cross_entropy，内部自动完成 Softmax 与 -log 计算）
- 优化器：AdamW（PyTorch 官方推荐，适配 Transformer 训练）
